# BRAND — демо интернет-магазина стритвира

Демо для показа заказчику: Laravel 11, Blade + Tailwind, Livewire 3 (корзина, фильтр, оформление),
SQLite, Filament 3 (админка). Оплата, доставка и рассылка — заглушки.

## Запуск

Нужны PHP 8.2+ (расширения `pdo_sqlite`, `intl`, `gd`), Composer, Node 20+.

```bash
cd shop
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate:fresh --seed   # таблицы, 12 товаров, 2 коллекции, placeholder-фото, админ
php artisan storage:link
npm install && npm run build
php artisan serve                  # http://localhost:8000
```

## Админка

`http://localhost:8000/admin` — логин `admin@brand.kz`, пароль `password`.

- **Товары** — CRUD, фото, цена и старая цена (скидка), размеры с остатками.
- **Коллекции** — дропы; отметка «Текущий дроп» определяет, что показано на главной.
- **Категории** — порядок перетаскиванием задаёт порядок в фильтре каталога.
- **Заказы** — список, смена статуса прямо в таблице или на странице заказа.

## Что является заглушкой

- **Оплата**: кнопка «Оплатить» создаёт заказ со статусом «Ожидает оплаты», деньги не списываются.
- **Доставка**: способ сохраняется в заказе, стоимость не считается.
- **Остатки** при заказе не списываются (заказ ещё не оплачен).
- **Рассылка**: e-mail проверяется, но никуда не сохраняется.
- **Фото** — SVG-силуэты, их генерирует сидер (`app/Support/Placeholder.php`).
- Тексты политик, размерные сетки и ссылки на соцсети — в `config/shop.php`.

## Где что лежит

- `app/Services/Cart.php` — корзина в сессии.
- `app/Livewire/` — счётчик и панель корзины, фильтр каталога, выбор размера, оформление заказа.
- `resources/views/` — страницы и компоненты; стили — `resources/css/app.css`, `tailwind.config.js`.
- `app/Filament/Resources/` — админка.
