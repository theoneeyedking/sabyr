# Сценарий демо

## Подготовка

```bash
make demo            # сеть Fabric, backend, шлюз, данные
cd mobile && npm install && EXPO_PUBLIC_API_URL=http://localhost:8000 npx expo start --web
```

Откройте три окна:

1. приложение — **Гульнара Сейткали**;
2. приложение во втором окне браузера (или на втором телефоне) — **Данияр Сейткали**;
3. обозреватель реестра — http://localhost:8090.

Чтобы повторить показ с чистого листа: `make seed` (отметка счёта в реестре при этом остаётся — для полностью
чистого реестра `make ledger-down && make demo`).

## Шаги

| № | Действие | Что видно |
|---|---|---|
| 1 | Войти как Гульнара. Пять раз нажать на логотип → демо-меню → включить «идёт звонок» (на Android с настоящим звонком сигнал придёт сам). | В меню видно, что сигнал активен. |
| 2 | Перевод → в демо-меню кнопка подставит счёт `KZ11SBA0000000007777` → сумма 1 500 000 → «Продолжить». | Экран Sabyr: риск больше 70, три причины на казахском, схема «Қауіпсіз шот», ассистент задаёт вопрос. |
| 3 | Обратить внимание на таймер и статус запроса. | Пауза 15:00, запрос отправлен Данияру, кнопка «Бәрібір аудару» неактивна. |
| 4 | Во втором окне — Данияр: на главной значок «1» у «Доверенное лицо» → открыть → «Отклонить». | У Гульнары экран сменился: перевод отклонён, деньги на счёте. |
| 5 | Окно обозревателя. | Новые строки: «Предупреждение клиенту» (Банк А, дважды) и «Счёт помечен как дроп». Только хэши. |
| 6 | Выйти, войти как Айдос Нурланов (Банк Б). Перевод 60 000 на тот же счёт, звонок выключен. | Сразу риск 85 и причина «Счёт получателя отмечен в межбанковском реестре…» — хотя Банк Б этот счёт раньше не видел. |

Дополнительно можно показать обычный перевод: Гульнара → `KZ22SBA0000000001111`, 20 000 ₸ — проходит без
вмешательства.

## Проверка без интерфейса

```bash
python scripts/demo_check.py     # те же шаги по HTTP, с проверками на каждом шаге
```

## Что рассказать по ходу

- Перевод не блокируется навсегда: решение остаётся за клиентом, но у него появляются время и собеседник.
- Причины объясняют, что именно насторожило систему — на языке клиента, без терминов.
- Реестр хранит доказательство: что показали клиенту и что он ответил. Это основа для разбора споров.
- Банки обмениваются отметками, не раскрывая друг другу клиентов: в реестре только хэши.
