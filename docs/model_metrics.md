# Метрики модели риска Sabyr

> Модель обучена **только на синтетических данных** (`ml/sabyr_ml/datagen.py`). Цифры показывают, что
> пайплайн работает и находит заложенные схемы; на реальных данных банка они будут ниже —
> модель нужно переобучать и калибровать на исторических кейсах банка.

Данные: 5000 клиентов, 199954 переводов за 90 дней, доля мошеннических 4.3%.
Разбиение по времени: обучение 113641, калибровка 22553, тест 53312 переводов.

## Модель риска (тестовый период)

Риск складывается из двух моделей LightGBM — «контекст отправителя» и «паспорт получателя»:
`risk = 1 − (1 − p_отправителя) · (1 − p_получателя)`.

| Метрика | Значение |
|---|---|
| ROC-AUC (итоговый риск) | 0.9993 |
| ROC-AUC только по контексту отправителя | 0.9798 |
| ROC-AUC только по паспорту получателя | 0.9991 |
| PR-AUC | 0.9873 |
| Precision при риске ≥ 40 (предупреждение) | 0.8273 |
| Recall при риске ≥ 40 | 0.9788 |
| Доля честных переводов, получивших предупреждение | 0.75% |
| Precision при риске > 70 (пауза) | 0.9344 |
| Recall при риске > 70 | 0.9533 |
| Доля честных переводов, попавших на паузу | 0.25% |
